변환 방향 · 옵션

치환 방식은 좌표를 규칙(X↔Y 교환·절삭축 부호 반전)으로 계산해 바꿉니다. 변환 후 아래 "밀링 치환 검증"에서 구간별로 원본과 나란히 비교하고, 치환 결과 / 등록된 검증 블록 / 원문 중에서 선택할 수 있습니다.

자동 적용 규칙: 헤더(G266·G125·G0B90.0M38·G300) 추가/제거 — G266은 W=길이+0.5, Z=183−길이 · G97↔G99 · G125Z0↔G120Z0 · T700/T7↔T3200/T22 · N200 숏컷 · 공구 주석

밀링 블록 관리제품별 R↔J 블록 쌍 — 이 PC 브라우저에 저장됩니다

+ 새 제품 블록 쌍 등록

등록한 블록은 브라우저(localStorage)에 저장됩니다. 다른 PC와 공유하려면 [내보내기]로 JSON 파일을 만들어 옮기세요.

생성 방식 선택

전용: 3.5mm 나사 규칙으로 즉시 생성. 범용: 제일 작은·큰 사이즈 프로그램 2개를 올리면 규칙을 파악해 중간 사이즈를 만듭니다.

AI 사이즈 생성짧은·긴 샘플에서 학습한 규칙으로 원하는 길이를 생성 · 3.5mm Locking Screw · 20J

규칙: 마지막 선삭 Z = L−3.56 · 로킹나사 Z = L−4.52 · 백터닝 Z = L−1.5 · 절단 Z = L+12.5 · 복귀 W = 183−L · 세그먼트 6.0mm 단위 (실제 프로그램 28개로 검증)

슬롯 프로그램 O번호 수량

프로그램 O번호를 넣으면 사이즈 주석(예: O3524 → (24mm))이 자동으로 붙습니다. 수량이 0이거나 비어 있으면 미사용 슬롯(수량 0.0 / O1000)으로 들어갑니다.

구조: 카운터 #511~519(영구 변수 — 중단 후 재시작 시 완료 슬롯 자동 스킵) · 목표 수량 #501~509 · 프로그램 번호 #101~109 · 슬롯 종료 시 다음 사이즈 첫 개 선가공 + O1000 호출

# CNC 프로그램 자동화 도구

> 2026 전남광주 청년 AI 솔버톤 본선대회 · **팀 A4**

CNC 스위스 자동선반의 NC 프로그램 작업(변환·생성·검증)을 자동화하는 웹 도구입니다.
숙련자만 알던 가공 규칙을 AI가 학습해 규칙으로 만들고, 실제 프로그램과 대조해 검증합니다.

## 🌐 배포 주소
**https://cnc-solverthon.netlify.app**

접속 후 각 탭의 **🧪 예제로 체험해보기** 버튼을 누르면 바로 동작을 확인할 수 있습니다.

## 주요 기능
| 기능 | 설명 |
|---|---|
| ① 매크로 변환 | 수백 줄 반복 프로그램을 매크로(WHILE 루프)로 압축, 서브프로그램 인라인 |
| ② 기종 변환 R↔J | 헤더·코드·밀링 축을 규칙으로 상호 변환, 구간별 재검토 |
| ③ AI 사이즈 생성 | 작은·큰 샘플 2개로 규칙을 학습해 원하는 중간 크기 생성 |
| ④ 사이클 생성 | 여러 제품을 순서·수량대로 자동 생산하는 스케줄 프로그램 |
| ⑤ 비교·검증 | 프로그램을 줄 단위로 대조 + 작업자 확인 서명/기록 |
| ⑥ 형상 비교 | 두 프로그램의 실제 가공 형상(단면)을 그려서 시각적으로 비교 |

## 작동 원리
1. **정답 학습** — 검증된 프로그램들을 AI가 비교·분석
2. **규칙 발견** — 길이 변화에 따른 값 변화를 선형 공식으로 도출 (LCS 정렬 기반)
3. **코드 실행** — 규칙대로 프로그램을 생성·변환
4. **검증** — 실제 프로그램과 줄 단위 대조 + 작업자 최종 확인

## 기술 구성
- **순수 HTML / CSS / JavaScript** — 프레임워크·서버 없음
- **100% 브라우저 로컬 처리** — 모든 처리가 브라우저 안에서만 실행되어, 프로그램이 외부로 전송되지 않습니다 (사내 데이터 보안)
- 규칙 엔진: `js/converter.js`(변환), `js/machine.js`(기종), `js/generator.js`·`js/interpolate.js`(사이즈), `js/cycle.js`(사이클)

## 실행 방법
```bash
# 정적 파일이라 브라우저로 index.html을 열기만 하면 됩니다.
# 로컬 서버로 보려면:
node tools/server.js   # http://localhost:8123
```

## 검증
- AI 생성 프로그램을 실제 현장 프로그램 28종과 줄 단위 대조 → **28/28 일치**
- 변환 규칙 6종 자동 검증 → **6/6 통과**
- 범용 사이즈 보간 결과 vs 실제 프로그램 → **99.6% 일치**

> 규칙 명세·검증 스크립트는 사내 데이터 보호를 위해 이 공개 저장소에서 제외했습니다.
